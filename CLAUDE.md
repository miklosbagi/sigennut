# sigennut — agent instructions

## Keep README.hu.md maintained

This repo ships a Hungarian translation, `README.hu.md`, alongside
`README.md`. Whenever a change touches `README.md`, update
`README.hu.md` in the same PR — don't let it drift out of sync.

Translate for a native Hungarian technical reader, not word-for-word.
Prefer the phrasing and terminology a Hungarian engineer would actually
use over a literal, mechanical translation — no cheap/robotic-sounding
translations. Code blocks, file paths, flag names, environment
variables, and other literal identifiers stay unchanged, exactly as in
the existing `README.hu.md`.
